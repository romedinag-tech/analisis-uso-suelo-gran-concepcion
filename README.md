# Análisis Uso de Suelo Gran Concepción

Diagnóstico exploratorio y evolución temporal 2021-2025 del uso EFECTIVO (fiscal) del suelo del Gran Concepción, a partir del catastro del SII.

Autor: Rodrigo Medina González — Universidad de Concepción.

Sitio publicado con GitHub Pages (index.html): KPIs, mapas por manzana (centroides), series temporales y un mapa interactivo (Leaflet) sobre manzanas.geojson.

Nota: se reporta uso EFECTIVO, no la zonificación normativa del Plan Regulador. KPIs de densidad poblacional pendientes por falta de crosswalk SII-INE/Censo. Mapas por centroide de manzana (sin capa vectorial de polígonos).
